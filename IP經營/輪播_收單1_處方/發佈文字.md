# 收單系列 1｜篇 3 處方：每單結束，只寫 3 件事

同一個錯，你犯過幾次？

停損到了，又往下移一點。
一虧就馬上反手，想把它賺回來。
看到在漲，沒想清楚就追。

你以為是運氣不好，
其實是同一個錯，一直在重複。
沒寫下來，大腦只會記得「下次一定會漲」。

所以每一單結束，我只寫 3 件事：

① 為什麼進場？能用一句話寫出來嗎？
② 有沒有照計畫出場？停損有沒有移、有沒有提早跑？
③ 下一單要改什麼？只寫一件就好。

寫 7 天，你會看到自己最常犯的那一個錯。
看得見，才改得掉。
